## Audio - public/audio/

Generated by `scripts/generate_audio.py` using Microsoft Edge neural TTS
voice `te-IN-ShrutiNeural` (via the open-source `edge-tts` client). These
are computer-generated clips, NOT human recordings; use in the app is
labelled as such. Clips whose text matched the earlier pilot
(D:\githubProjects\DailyTeluguLearning) were copied from it; the rest
were generated.

Pronunciation correctness is NOT established by generation or successful
playback. Review status is tracked in the app's /audio-review page
(localStorage key `daily-telugu-audio-review`) and needs a native Telugu
speaker's approval before the audio is described as reviewed.
